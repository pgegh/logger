# logger

A basic event logger.

## Key Features

- **Basic Logging**: Log events to log files.
- **Log Levels**: Log with levels: *Info*, *Warning*, and *Error*.
- **Log File rotation**: A configurable log file rotation to avoid exhausting system resources.

## Technologies

- **Code Base**: [Rust](https://www.rust-lang.org/)
